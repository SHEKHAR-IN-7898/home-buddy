# Home Buddy

Modern full-stack home services platform for booking trusted professionals and helping service businesses manage bookings, workers, customers, and revenue.

## Highlights

- Mobile-first customer experience
- Customer and business role flows
- Service catalog and booking APIs
- Business operations dashboard
- Buddy AI home-service assistant
- PostgreSQL persistence through Hatchable
- Responsive UI

## Live demo

https://home-buddy.hatchable.site

## Structure

- `public/` — customer and business web UI
- `api/` — backend API endpoints
- `migrations/` — database schema
- `seed.sql` — initial service data

## Deployment

The application is currently hosted on Hatchable. Hatchable provides the runtime integrations for database, authentication, and AI used by the project.
